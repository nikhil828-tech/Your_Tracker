# Interest Calculator Web Application

## Description
This project is a web-based Interest Calculator application developed as part of the
**Web Development (Oct)** course. The application helps users calculate simple interest
and manage lending or borrowing accounts using a clean and user-friendly interface.

The project is built using a full-stack approach and follows the MERN stack architecture.

---

## Features
- User Registration and Login
- Dashboard with summary information
- Account management (Investors and Customers)
- Simple Interest Calculator
- Transaction tracking
- Notifications section
- Profile management

---

## Technology Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JSON Web Token (JWT)
